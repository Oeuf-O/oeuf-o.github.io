Four ways to understand an image

A quick guide to influential models for object detection, semantic segmentation, instance segmentation, and panoptic segmentation.

Object detectionSemantic segmentationInstance segmentationPanoptic segmentation
At a glance: Detection draws boxes around objects. Semantic segmentation labels every pixel by category. Instance segmentation gives each object its own pixel mask. Panoptic segmentation combines semantic labels with separate masks for individual objects.

Object detection

ModelCore ideaTypical strength / tradeoff
R-CNNCreates candidate image regions, then runs a CNN on each region to classify it and refine its box.Landmark accuracy gains; slow because CNN work is repeated. Paper
Fast R-CNNRuns the CNN once on the whole image, then uses shared features to classify and refine proposed regions.Much faster than R-CNN; still depends on a separate proposal method. Paper
Faster R-CNNAdds a Region Proposal Network (RPN) that shares image features with the detector.Accurate, strong two-stage baseline; usually slower than one-stage models. Paper
SSDPredicts classes and boxes in one pass at multiple feature-map scales.Designed for speed; multiple scales help with differently sized objects. Paper
YOLOPredicts boxes and classes directly from the full image in one pass.Real-time design; the family has evolved substantially across versions. Original paper
RetinaNet Recommended additionOne-stage detector using focal loss to focus training on harder examples instead of abundant easy background examples.Helped close the accuracy gap between one-stage and two-stage detectors. Paper
DETR Recommended additionUses a transformer and set prediction for end-to-end detection, without hand-designed anchors or the usual NMS step.Introduces a different, transformer-based detection approach. Paper

A useful historical progression is R-CNN → Fast R-CNN → Faster R-CNN: each step reduces the cost of proposing and processing candidate regions.

Semantic segmentation

ModelCore ideaTypical strength / tradeoff
FCNTurns classification networks fully convolutional to predict pixel labels; skip connections combine coarse semantics and finer detail.Established end-to-end dense prediction as a standard approach. Paper
SegNetEncoder–decoder architecture; decoder uses max-pooling indices from the encoder to upsample features.Designed for efficient scene segmentation and memory use. Paper
U-NetSymmetric contracting and expanding paths with skip connections between matching resolutions.Works well with limited annotated data; especially popular in biomedical imaging. Paper
DeepLabv2Uses atrous (dilated) convolutions and ASPP to capture context at multiple scales; the original system also used CRF refinement.Captures broad context while retaining spatial resolution. Paper
DeepLabv3Improves multi-scale context with parallel or cascaded atrous modules and image-level features.Strong segmentation without requiring the earlier CRF post-processing. Paper
PSPNetUses pyramid pooling to gather scene context at several spatial scales.Wider scene context helps resolve ambiguous pixels. Paper
DeepLabv3+ Recommended additionExtends DeepLabv3 with a decoder to recover object boundaries and spatial detail.A useful follow-up to DeepLabv3. Paper

A useful distinction: U-Net and SegNet emphasize encoder–decoder recovery of detail, while DeepLab and PSPNet emphasize multi-scale context.

Instance segmentation

ModelCore ideaTypical strength / tradeoff
Mask R-CNNExtends Faster R-CNN with a parallel mask branch, producing a separate pixel mask for each detected object.Flexible, influential baseline; its two-stage design is not primarily aimed at real-time speed. Paper
YOLACTPredicts shared prototype masks and combines them with per-object coefficients.Designed for real-time instance segmentation. Paper
YOLACT++ Recommended additionImproves YOLACT with changes including better localization and an improved mask-coefficient branch.Follow-up for its speed and mask quality tradeoffs. Paper
Cascade Mask R-CNN Recommended additionCombines instance masks with a cascade of detectors trained at increasingly strict box-quality thresholds.Shows how a strong two-stage baseline can be refined. Paper

Panoptic segmentation

ModelCore ideaWhy learn it
Panoptic FPNAdds a semantic-segmentation branch to Mask R-CNN and shares a feature pyramid between both branches.A clear baseline for combining individual object masks with labels for background regions. Paper

Suggested reading order

Build up the ideas from foundational architectures to combined and speed-focused models:

  1. FCN
  2. Faster R-CNN
  3. YOLO or RetinaNet
  4. U-Net
  5. DeepLabv3
  6. Mask R-CNN
  7. YOLACT
  8. Panoptic FPN

Note: “Mask R-CNN” is assumed to be the intended model where “Mark R-CNN” was written.
