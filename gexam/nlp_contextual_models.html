Natural language processing · model overview

From Word2Vec to contextual language models

How sequence models such as RNNs, BiRNNs, seq2seq, and ELMo represent words using their context.

The key idea

Your intuition is broadly right: Word2Vec and fastText usually assign one vector to each word form, while recurrent models can build representations that change with the surrounding words.

Example: “river bank” and “bank account” contain the same word, but a contextual model can represent bank differently in each sentence.

RNNs were not developed only to fix static embeddings. They were also designed to model ordered sequences. Later systems, including ELMo, used recurrent language models to produce context-sensitive word representations.

Important models

ModelHow it worksWhat it adds
RNNReads tokens one at a time and updates a hidden state that carries information from earlier tokens.Uses sequence order and preceding context. Basic RNNs can struggle to retain information over long distances.
LSTM / GRURNN variants with gates that control which information to keep, update, or discard.Handle longer dependencies better than basic RNNs; widely used building blocks for language and sequence tasks.
BiRNNRuns one RNN left-to-right and another right-to-left, then combines their states.Can use both earlier and later context. Useful when the full input is available, such as tagging or sentence classification.
Seq2seqAn encoder RNN reads the input; a decoder RNN generates the output sequence.Maps sequences of different lengths, such as a source sentence to a translation. Early versions compressed the input into one fixed-size vector, limiting long inputs.
Seq2seq with attentionAt each output step, the decoder can focus on relevant encoder states instead of relying only on one summary vector.Improves input-output alignment and helps with longer sequences. Attention later became central to Transformers.
ELMoA deep bidirectional language model predicts next words in one direction and previous words in the other; its internal states are combined for each word.Produces contextual word vectors. It was commonly added as a pretrained feature for a downstream task model.

How the ideas build on each other

Word2Vec / fastTextMostly fixed word vectors
RNN language modelsOrdered sequence states
BiRNNContext from both directions
Seq2seqSequence-to-sequence tasks
ELMoPretrained contextual vectors

This is a conceptual progression, not a strict sequence of replacements: these architectures address related but different tasks.

Where Transformers fit

ELMo was an important step toward contextual representations. BERT and other Transformer models pursue the same broad idea—represent words using their context—but use attention instead of recurrent state updates.
