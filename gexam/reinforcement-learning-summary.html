Reinforcement Learning

A concise guide to how an agent learns from actions and rewards, and how SARSA, Q-learning, temporal-difference learning, dynamic programming, and Monte Carlo relate.

1. The basic interaction

An agent observes a state, chooses an action, and receives a reward while the environment moves to a new state. The agent aims to choose actions that maximize reward over time.

PolicyThe agent’s rule for choosing an action in a state.
Action value Q(s,a)An estimate of the future reward from taking action a in state s and then continuing.

2. On-policy and off-policy

These terms describe how the policy that generates experience relates to the policy being learned.

On-policyLearns about the same policy that is currently choosing actions. Its updates reflect how that policy behaves, including exploration.
Off-policyLearns about a target policy using experience generated by a different behavior policy. This lets it learn from varied behavior or stored experience.

3. SARSA and Q-learning

Both are temporal-difference control methods. They learn action values from individual transitions, but use different estimates for what happens next.

MethodPolicy typeNext-step targetIntuition
SARSAOn-policyValue of the next action actually selectedLearns the value of the behavior it is following, including exploration.
Q-learningOff-policyHighest estimated action value in the next stateLearns toward greedy action choices, even if behavior still explores.
SARSA: Q(s,a) ← Q(s,a) + α [ r + γ Q(s′,a′) − Q(s,a) ]
Q-learning: Q(s,a) ← Q(s,a) + α [ r + γ maxₐ′ Q(s′,a′) − Q(s,a) ]

α is the learning rate; γ discounts future rewards; r is the reward received. In SARSA, a′ is the action actually taken next.

Risky-shortcut intuition

If exploration near a cliff can cause a fall, SARSA accounts for the risk of its exploratory behavior and may favor a safer route. Q-learning evaluates the best next action, so it can favor a shorter route near the edge.

4. What “temporal difference” means

TD learning updates a current estimate using a target that combines the reward just observed with an estimate of future value. The difference between the target and current estimate is the TD error.

TD(0) state-value update: V(s) ← V(s) + α [ r + γ V(s′) − V(s) ]

This update can happen after one step. It does not need to wait for the episode to finish, because it uses the current estimate of the next state’s value. This use of an estimate as part of the target is called bootstrapping. SARSA and Q-learning apply the same general principle to action values.

5. Dynamic programming, Monte Carlo, and TD

All three are ways to estimate values or improve decisions. They differ in what information they use and when they update.

ApproachUsesUpdate timingBootstraps?Needs environment model?
Dynamic programming (DP)Known transition and reward rules; considers possible outcomesRepeated planning updates over statesYesYes
Monte Carlo (MC)Sampled episodes and their actual total returnsUsually after an episode endsNoNo
Temporal difference (TD)Sampled transitions: reward and next stateCan update after each stepYesNo

Journey example: DP uses known travel rules to compute expected remaining time; MC completes a journey and learns from its total time; TD updates after a step using the time spent plus an estimate of the remaining journey.

6. How they fit together

Reinforcement learning
Agent learns to act from reward feedback.

TD learning
Updates estimates from a sampled transition and a bootstrapped next-value estimate.

SARSA and Q-learning
TD methods for learning action values and improving a policy.

Key difference
SARSA learns from the next action taken; Q-learning backs up the best estimated next action.
