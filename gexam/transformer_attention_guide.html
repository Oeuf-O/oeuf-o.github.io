Transformers and attention

How Transformers build context-sensitive representations, how multi-head attention works, and how models learn to use attention.

What is a Transformer?

A Transformer is a neural-network architecture for processing sequences such as text. Its central mechanism is attention: tokens can use information from other tokens in the sequence to update their representations.

Unlike an RNN, which processes tokens one at a time and passes information through a recurrent state, a Transformer can connect tokens directly through attention. During training, it can usually process the tokens in parallel.

Example: In “The animal didn’t cross the road because it was tired,” attention can allow the representation of it to use information from animal and other words in the sentence.

Typical processing steps

1. TokenizeSplit text into tokens, often word pieces.
2. EmbedMap each token to a learned vector.
3. Add positionSupply information about token order.
4. AttendLet tokens gather relevant context.
5. TransformApply feed-forward layers; repeat in stacked blocks.

Attention by itself does not encode sequence order, so Transformers add positional information to token representations.

Self-attention: how tokens exchange information

In self-attention, each token compares itself with other tokens in the same sequence. The model creates three learned projections for each token:

Query

What information is this token looking for?

Key

What information does each token offer for matching?

Value

What information can each token contribute?

The model compares a token’s query with other tokens’ keys to calculate attention weights. It then uses those weights to combine the corresponding values. A high weight means that token contributes more to the updated representation.

Queries, keys, and values are learned from data. People do not specify in advance which words should connect.

Multi-head attention

Multi-head attention runs several attention operations in parallel. Each head has its own learned query, key, and value projections, so the heads can gather different information at the same time.

For the word it, one head might give more weight to animal, while another might use tired or the clause introduced by because. The model joins the heads’ outputs and transforms them into a new token representation.

Across layers, these updates let the model build richer representations from the surrounding sentence.

Heads do not have fixed human-assigned jobs. A head is not explicitly labeled “pronoun finder.” Heads may learn useful patterns, but their roles vary and are not necessarily easy to interpret.

Attention weights indicate where a head draws information from, but they do not necessarily explain the model’s full reasoning.

Is a Transformer supervised learning?

Transformer describes an architecture, not a training type. A Transformer can be trained with supervised, self-supervised, or combined objectives.

  1. A training objective supplies a signal. For example, a language model may predict the next token, or predict masked tokens.
  2. Predictions are compared with their training targets. The resulting errors are used to adjust the model’s parameters, including its attention projections.
  3. Useful patterns emerge across many examples. Relationships between pronouns, nouns, and surrounding meaning can help improve predictions.

The model usually is not given a separate label that says “it refers to animal.” It learns from the task’s training signal. Many layers and heads contribute to a prediction; no single attention link necessarily contains the whole interpretation.

Sentences can be ambiguous. The model learns likely interpretations from patterns and context rather than applying a guaranteed grammar rule.

Source–target attention (cross-attention)

In an encoder–decoder Transformer, the encoder reads a source sequence and produces representations for its tokens. The decoder generates a target sequence. In source–target attention, also called cross-attention, the decoder uses encoder representations as context while generating each output token.

Translation example
Source: “The cat is sleeping.”
Target: “Le chat dort.”
The decoder can attend to source words while generating each translated word.

Cross-attention itself is not a learning type. When a model is trained on paired source and target examples, that training is supervised: the model learns to generate the provided target. It usually is not given explicit word-to-word alignment labels. Encoder–decoder models can also use other objectives, such as reconstructing corrupted text.

Common Transformer forms

Encoder-only

Example: BERT. Uses context from both directions; often used for text understanding and classification.

Decoder-only

Example: GPT. Predicts the next token from preceding tokens; commonly used for text generation.

Encoder–decoder

Examples: original Transformer, T5. Encodes an input and generates an output, as in translation.

Transformers can capture relationships between distant tokens directly, which is useful for long-range context. Standard self-attention compares tokens with one another, so its compute and memory costs grow roughly with the square of sequence length. Very long inputs can therefore be expensive.
