A visual primer

How Image Generation Systems Work

VAEs, GANs, and diffusion models learn to create images in different ways. NeRF is related to visual AI, but solves a different problem: representing a 3D scene so it can be rendered from new viewpoints.

The big picture: a model learns a representation of visual patterns from training data, then uses that representation to create, reconstruct, or render images. Text-to-image systems usually add a text encoder that turns a prompt into guidance for image creation.

1. The main image-generation techniques

Compress and reconstruct

VAE · Variational Autoencoder

A VAE encodes an image into a probability distribution in a compact latent space, samples a code from that distribution, then decodes the code back into an image. Sampling new codes can produce new images; the same encoder-decoder structure is also useful for compression and editing.

Image→Encoder → latent distribution→Decoder → image

Where KL divergence fits: the encoder predicts a distribution such as q(z|x) = N(μ, diag(σ²)). A KL-divergence penalty encourages it to stay near a simple prior, usually N(0, I). This makes the latent space more regular and easier to sample from.

Loss = reconstruction error + β · KL(q(z|x) || N(0,I))

The reconstruction term rewards faithful images; the KL term regularizes latent codes. Too much KL pressure can soften reconstructions, while too little can make sampling less well-behaved. β-VAE adjusts this balance.

Compete to improve

GAN · Generative Adversarial Network

A generator creates images from random input. A discriminator tries to distinguish generated images from real ones. Training these networks in competition pushes the generator toward convincing outputs.

Random code→Generator→Synthetic image↔Discriminator

GANs can produce sharp images and offer useful latent-space controls. Training can be unstable, and a GAN may produce less variety if it fails to cover some modes of its training data.

Enhancements: StyleGAN introduced a style-based generator for more direct control over visual attributes. StyleGAN2 improved image quality, and StyleGAN3 adjusted signal processing to reduce aliasing and details that seem fixed to pixel coordinates.

Iteratively remove noise

Diffusion models

Training gradually adds noise to real images and teaches a network to predict or remove it. Generation runs this process in reverse: start with random noise and repeatedly denoise until a coherent image appears.

Random noise→Denoise→Denoise again …→Image

Text-to-image models encode the prompt and use it to guide denoising, commonly through attention mechanisms. Diffusion is flexible and produces detailed, varied results, though each generation may require many computation steps.

Enhancements: latent diffusion runs denoising in a compressed representation rather than directly over all pixels. Faster samplers reduce the number of denoising steps; guidance, inpainting, image-to-image tools, and structure controls steer the result. Cascaded or refinement stages can improve resolution and detail.

Often combined

How these pieces fit together

These are not always competing, standalone choices. A system can combine them. Stable Diffusion, for example, uses a VAE to encode and decode images and a diffusion model to create the latent image. Its text encoder supplies prompt conditioning.

In this arrangement, the VAE is the image representation and decoder; diffusion is the generative process. A GAN-trained objective may also be used while training an autoencoder to improve visual sharpness.

A useful distinction: “VAE” may refer to the whole generative model or, in a larger system, just the autoencoder component.

Generative AI keeps evolving. Not every current image system uses VAE, GAN, or diffusion as its main generation method. For example, OpenAI’s 2025 system card describes GPT‑4o image generation as autoregressive. Systems can also combine techniques internally.

3. NeRF: a neural representation of a 3D scene

NeRF means Neural Radiance Field. It represents a particular scene as a continuous function learned by a neural network. Given a 3D location and a viewing direction, the network predicts the point’s density and the color it emits toward that view.

Several photos + camera poses→Train a neural scene→Render unseen viewpoints

To render a pixel, the system traces a ray from the camera, samples points along it, queries the field, and blends the predicted colors and densities using volume rendering. It compares rendered views with the source photos and adjusts the network to make them match.

(x, y, z, viewing direction) → (density, color)

NeRF is best understood as scene reconstruction and novel-view synthesis, rather than ordinary text-to-image generation. It can create a convincing view as a camera moves around a captured scene, without first building a conventional textured mesh. The original method can be slow; Instant-NGP’s multiresolution hash encoding is one approach that made neural graphics primitives much faster to train and evaluate.
