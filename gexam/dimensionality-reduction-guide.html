A practical introduction

Reducing Dimensions: Methods and When to Use Them

Dimensionality reduction turns a dataset with many variables into a smaller representation. It can make models faster, reduce noise or redundancy, and help visualize data—but different techniques preserve different properties, so a two-dimensional picture is not a neutral map of the full dataset.

First distinction: Feature selection keeps a subset of the original columns. Feature extraction creates new, compressed variables from combinations or transformations of the originals. Selection keeps variables interpretable; extraction can compress more aggressively, but the resulting dimensions may be harder to explain.

Practical rule: If the goal is better prediction, choose dimensionality reduction inside the training and validation pipeline, then judge it by the downstream task. If the goal is a plot, treat the embedding as a visualization aid; do not interpret distances, cluster sizes, or gaps as exact facts unless the method is designed to preserve them.

Linear and supervised projections

1. Principal Component Analysis (PCA) Unsupervised, linear

PCA finds new, perpendicular axes (principal components) that capture as much variance in the data as possible. The first component captures the greatest variance; each next component captures the most remaining variance while being orthogonal to earlier ones. Data are projected onto the first k components, reducing the number of coordinates.

Given centered X = UΣVᵀ, keep top k columns Vₖ:
Z = XVₖ; maximize variance of each successive projection

Example: A dataset has 100 correlated sensor measurements. PCA may summarize their shared trends using 10 components, retaining most overall variation.

Useful for: Compression, denoising, visualization before a classifier, or reducing multicollinearity. Standardize features first when their measurement units or scales differ substantially.

Limitations: Components are linear combinations and may not map neatly to meaningful variables. PCA ignores target labels, so a low-variance feature that predicts the outcome well can be discarded. It captures linear patterns, and outliers can strongly affect it.

2. Truncated Singular Value Decomposition (SVD) Unsupervised, linear

SVD factorizes a matrix into orthogonal directions and importance weights. Truncated SVD keeps only the largest k directions, producing a low-rank approximation. It is closely related to PCA; unlike common PCA implementations, it can operate directly on sparse matrices without centering them first.

X ≈ UₖΣₖVₖᵀ
Coordinates for rows: UₖΣₖ

Example: A document-term matrix may have tens of thousands of word columns. SVD can compress it into a smaller set of latent directions that represent recurring co-occurrence patterns.

Useful for: Sparse text data, latent semantic analysis, and low-rank approximation of large matrices.

Limitations: Components are mixtures of original features and can be hard to name. Like PCA, it captures variance/approximation error rather than necessarily preserving what predicts a label.

3. Linear Discriminant Analysis (LDA) projection Supervised

As a dimensionality-reduction technique, LDA uses labels to find projections that separate classes: it seeks directions with large between-class variation compared with within-class variation. It differs from LDA as a classifier, though both use the same class-separation idea.

Choose W to maximize
det(WᵀSᵦW) / det(WᵀS𝑤W)
Sᵦ = between-class scatter; S𝑤 = within-class scatter

Example: For labeled flower species, LDA can project measurements into a few axes that make the known species easier to distinguish.

Useful for: Classification pipelines and labeled visualizations when the classes are meaningful.

Limitations: Requires labels, and it can produce at most C−1 discriminant axes for C classes. It may miss nonlinear class boundaries and can overfit when there are many features but few labeled examples.

Distance and neighborhood embeddings

4. Multidimensional Scaling (MDS) Distance-based

MDS places points in a low-dimensional space so that distances in the map resemble supplied pairwise dissimilarities. Classical MDS derives coordinates from distances using an eigen-decomposition; metric MDS directly minimizes a stress score, while non-metric MDS aims to preserve the rank order of dissimilarities.

Stress = √[Σᵢ<ⱼ(dᵢⱼ − δᵢⱼ)² / Σᵢ<ⱼ δᵢⱼ²]
δᵢⱼ = input dissimilarity; dᵢⱼ = map distance

Example: A survey gives perceived dissimilarities among 30 brands. MDS can make a two-dimensional map where brands judged similar sit near each other.

Useful for: Visualizing data when you already have a meaningful distance or dissimilarity matrix, including non-Euclidean distances.

Limitations: A good low-dimensional fit may not exist; stress and initialization matter. Pairwise distances need O(n²) storage, so MDS can become costly as the number of samples grows.

5. t-distributed Stochastic Neighbor Embedding (t-SNE) Nonlinear visualization

t-SNE converts distances into probabilities of neighborhood relationships in the original space, then searches for a low-dimensional map with similar neighborhood probabilities. A heavy-tailed Student-t distribution in the map helps separate points that would otherwise crowd together.

Minimize KL(P || Q) = Σᵢⱼ pᵢⱼ log(pᵢⱼ/qᵢⱼ)
P: high-dimensional neighbor probabilities; Q: map probabilities

Example: Plot handwritten digit images as dots. Images of similar digits often form nearby islands, helping an analyst inspect local groupings.

Useful for: Exploratory 2D/3D visualization of local neighborhood structure, especially after reducing very wide data with PCA or SVD.

Limitations: Distances between separate clusters, empty gaps, cluster sizes, and apparent global layout are not generally reliable measures of the original geometry. Results vary with perplexity, initialization, and random seed; standard t-SNE is mainly for embedding the data it was fit on, not mapping future points.

6. UMAP Nonlinear graph embedding

Uniform Manifold Approximation and Projection builds a weighted nearest-neighbor graph in the original space, then optimizes a lower-dimensional graph to retain similar connections. The neighborhood count controls how local or broad a view is emphasized; minimum distance controls how tightly points may pack in the map.

Build fuzzy neighbor graph G in input space;
find embedding Z whose fuzzy graph best matches G

Example: Embed thousands of text or image vectors into 2D to inspect local groupings and possible subgroups.

Useful for: Fast nonlinear visualization, and sometimes creating features for downstream tasks. UMAP also supports embeddings with more than two dimensions.

Limitations: The map depends on metric, neighborhood size, minimum distance, and random state. Close neighborhoods are emphasized, but global distances and apparent clusters should still be treated cautiously. If using an embedding for prediction, test it within a leakage-safe validation pipeline.

7. Isomap Manifold learning

Isomap assumes data lie on a curved, lower-dimensional surface embedded in a high-dimensional space. It connects near neighbors into a graph, estimates distances along the graph (geodesic distances), and then uses an MDS-like step to map points into fewer dimensions.

k-neighbor graph → shortest-path distances Dᵍ → MDS embedding

Example: A rolled sheet (“Swiss roll”) is two-dimensional but folded through three-dimensional space. Straight-line distances can make distant parts appear close; Isomap tries to preserve distance along the unrolled surface.

Useful for: Exploratory visualization when a smooth, connected manifold and meaningful local neighborhood graph are plausible.

Limitations: A poor neighbor graph can create shortcuts or disconnected regions. Noise and outliers can distort shortest paths; graph construction and computation can be demanding for large datasets.

8. Locally Linear Embedding (LLE) and spectral embedding Manifold learning

LLE describes each sample as a weighted combination of nearby samples, then finds low-dimensional coordinates that preserve those local reconstruction weights. Spectral embedding (Laplacian Eigenmaps) builds a neighbor graph and places strongly connected points near each other by solving an eigenvector problem on its graph Laplacian.

LLE: preserve xᵢ ≈ Σⱼwᵢⱼxⱼ in low-dimensional zᵢ
Spectral: solve eigenvectors of graph Laplacian L = D − A

Example: On a curved surface, nearby points may have a locally flat neighborhood. LLE can preserve these small-scale relationships without requiring one global linear projection.

Useful for: Nonlinear exploratory embeddings when local geometry is the main interest.

Limitations: Neighborhood size and graph quality are critical; noise, uneven density, or disconnected regions can cause failures. Many variants do not provide a simple transform for embedding unseen future samples.

Fast, parts-based, and learned representations

9. Random projection Fast linear sketch

Random projection multiplies the data by a random matrix to map it into fewer dimensions. With an appropriate target size, pairwise distances are likely to remain approximately similar (the Johnson–Lindenstrauss principle), even though the new axes are not selected to capture a particular data pattern.

Z = XR, where R has random entries
Choose output dimension so pairwise distances are approximately preserved

Example: Compress millions of sparse vectors before a nearest-neighbor search, reducing storage and computation while approximately maintaining similarity.

Useful for: Fast, memory-efficient preprocessing of very wide datasets where preserving distances approximately is enough.

Limitations: Results are not tailored to the dataset and are difficult to interpret. The approximation has finite error, and downstream performance should be checked across random seeds.

10. Non-negative Matrix Factorization (NMF) Parts-based factorization

NMF approximates a non-negative data matrix as the product of two smaller non-negative matrices. Each observation becomes a combination of latent components; non-negativity can make these combinations additive and sometimes more interpretable than PCA’s positive-and-negative mixtures.

X ≈ WH, with W ≥ 0 and H ≥ 0
Choose W,H to minimize reconstruction error

Example: In document analysis, components may capture topics as collections of words, and each document is represented by its topic weights.

Useful for: Nonnegative counts, intensities, or signals where additive parts make sense—such as word counts, image pixels, and some spectroscopy data.

Limitations: Inputs must be nonnegative; the factorization is not generally unique and can depend on initialization. Components are not guaranteed to align with meaningful concepts.

11. Autoencoders Neural feature extraction

An autoencoder learns an encoder that compresses inputs into a lower-dimensional code and a decoder that reconstructs the input from that code. Training minimizes reconstruction error, often with regularization or a deliberately narrow “bottleneck.”

z = fθ(x);   x̂ = gφ(z)
Train θ,φ to minimize Σᵢ ℓ(xᵢ, x̂ᵢ)

Example: An image autoencoder may encode each image as a compact vector, then reconstruct its main patterns from that vector.

Useful for: Large, complex data such as images or signals, nonlinear compression, denoising, and learned features for later models.

Limitations: A representation that reconstructs well need not preserve the feature relevant to a later prediction. Training and architecture choices matter, and the learned dimensions are usually less interpretable than original features.

12. Feature selection Keep original columns

Feature selection removes columns rather than combining them. Filter methods rank variables using statistics (such as correlation or mutual information); wrapper methods evaluate feature subsets using a model (such as recursive feature elimination); embedded methods select or shrink features during training (such as Lasso or tree-based selection).

Filter: rank score(xⱼ, y) → keep top k
Wrapper: evaluate subsets with validation
Embedded: selection is part of model fitting

Example: A medical risk model might retain a small set of lab values and age instead of dozens of redundant measurements, leaving the final inputs recognizable to clinicians.

Useful for: Improving interpretability, reducing measurement cost, removing constant or irrelevant fields, and simplifying models.

Limitations: A variable can be useful only through interactions and may look weak when evaluated alone. Correlated variables can make selection unstable. Any target-informed selection must be performed within each training fold to prevent data leakage.

How to choose

Match the method to the goal
GoalGood candidatesQuestion to ask
Reduce redundancy before predictionPCA, SVD, regularized modelsDoes the transformation improve validation performance?
Keep variables human-readableFeature selectionAre selections stable across folds or samples?
Visualize labeled class separationLDA; PCA as a label-free baselineAre labels available and is a linear projection adequate?
Visualize local neighborhoodst-SNE, UMAPAm I treating the plot as exploratory rather than a precise global map?
Preserve given dissimilaritiesMDSIs my distance metric meaningful for the domain?
Capture a curved manifoldIsomap, LLE, spectral embedding, UMAPIs the neighborhood graph trustworthy?
Compress a huge sparse matrix quicklyTruncated SVD, random projectionDo I need components to be interpretable?

For prediction, do not reduce to two dimensions just because plots are convenient; choose a dimension count using validation performance. Fit scaling, feature selection, and the projection using training data only. For plots, compare more than one method or setting and validate surprising patterns in the original feature space.
