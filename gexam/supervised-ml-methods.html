A practical introduction

Major Methods of Supervised Machine Learning

Supervised learning uses examples with known answers to learn a mapping from input features to a target. This guide compares widely used regression and classification methods, gives a compact form of each method’s core formula, and describes when it tends to be useful.

Notation: Training examples are (xᵢ, yᵢ), where xᵢ is the feature vector and yᵢ is the target. A “loss” measures prediction error; training generally chooses model parameters to reduce average loss. Formulas below are canonical simplified versions, not every implementation detail. Classification and regression variants exist for several methods.

Linear and probabilistic models

1. Linear regression Regression

Key idea. Predict a numeric outcome as a weighted sum of input features. Ordinary least squares chooses coefficients so squared prediction errors are as small as possible.

ŷ = β₀ + β₁x₁ + ⋯ + βₚxₚ
β̂ = argminβ Σᵢ (yᵢ − xᵢᵀβ)²

Pros: Fast, simple, interpretable, and a useful baseline; coefficients show the direction and size of each feature’s association when other features are held fixed.

Cons: Assumes an additive linear relationship as written; sensitive to outliers and multicollinearity, and ordinary least squares can overfit when there are many features.

Suitable for: Predicting prices, demand, or measurements when relationships are approximately linear, and settings where a transparent baseline is important. Curvature and interactions can be modeled by adding transformed or interaction features.

2. Logistic regression Classification

Key idea. Despite its name, this is a classification method. It estimates the probability of a class by applying a sigmoid to a linear score; multiclass versions commonly use softmax.

P(y=1 | x) = σ(β₀ + xᵀβ),   σ(z)=1/(1+e⁻ᶻ)
β̂ = argminβ −Σᵢ[yᵢlog pᵢ +(1−yᵢ)log(1−pᵢ)]

Pros: Fast, interpretable, produces probabilities, and works well as a baseline. Regularization is available for many-feature problems.

Cons: Its boundary is linear in the features unless you add transformations; probabilities can be poorly calibrated if assumptions or data shift are problematic.

Suitable for: Binary or multiclass classification such as churn, screening, and risk ranking—especially when you want a compact model and reasonably explainable feature effects.

3. Ridge, Lasso, and Elastic Net Regularized linear models

Key idea. These extend linear or logistic models by penalizing large coefficients. Ridge uses a squared-coefficient penalty; Lasso uses absolute values and can drive some coefficients to zero; Elastic Net combines both.

Ridge: minimize L(β) + λΣⱼβⱼ²
Lasso: minimize L(β) + λΣⱼ|βⱼ|
Elastic Net: L(β) + λ[αΣ|βⱼ| +(1−α)Σβⱼ²]

Pros: Reduce overfitting; Ridge handles correlated predictors smoothly, while Lasso can provide a sparse, simpler model. Strong choices when there are many features.

Cons: Need to tune penalty strength; Lasso may select one of several correlated features somewhat arbitrarily. Feature scaling is usually important.

Suitable for: Regression or classification with many or correlated variables, such as text features, economic predictors, and small-sample scientific data. Choose Ridge for stable shrinkage, Lasso when sparsity is useful, and Elastic Net as a compromise.

4. Naive Bayes Classification

Key idea. Apply Bayes’ rule to estimate a class from its prior probability and feature likelihoods, assuming features are conditionally independent given the class. Common variants model counts, binary indicators, or continuous values differently.

P(y | x₁,…,xₚ) ∝ P(y) ∏ⱼ P(xⱼ | y)
ŷ = argmaxᵧ P(y) ∏ⱼ P(xⱼ | y)

Pros: Very fast, works with little training data, handles many sparse features, and can be an excellent text-classification baseline.

Cons: Real features are often dependent, which can make probability estimates inaccurate. The simplifying assumption can reduce accuracy when feature interactions matter.

Suitable for: Spam filtering, document/topic classification, sentiment baselines, and fast classification of sparse word-count data.

5. Linear / Quadratic Discriminant Analysis (LDA / QDA) Classification

Key idea. Model the features for each class as a Gaussian distribution and use Bayes’ rule. LDA assumes classes share one covariance matrix and yields linear boundaries; QDA estimates a covariance matrix per class, allowing quadratic boundaries.

P(x | y=k) = 𝒩(x; μₖ, Σₖ)
LDA: Σₖ = Σ for all k; QDA: separate Σₖ

Pros: Fast, naturally handles multiple classes, and can work well with modest datasets when the Gaussian assumptions are reasonable. LDA also supports supervised dimensionality reduction.

Cons: Performance depends on distribution and covariance assumptions. QDA estimates more parameters and can be unstable with limited data; LDA may be too restrictive if class boundaries curve.

Suitable for: Classification when class-specific feature distributions look roughly bell-shaped; LDA for simpler linear separation, QDA when curved boundaries are plausible and each class has enough examples.

Trees and ensembles

6. Decision tree Regression & classification

Key idea. Repeatedly split the data using feature-based questions, then predict with the average target or majority class in each final region. Training chooses splits that reduce impurity or prediction loss.

At node t, choose split s to maximize
ΔI = I(t) − [nL/n·I(L) + nR/n·I(R)]

Pros: Captures nonlinearities and feature interactions, usually needs little scaling, handles mixed feature patterns, and can be visualized as if-then rules.

Cons: A deep tree can memorize training data. Small data changes can produce a very different tree, and a single tree is often less accurate than ensembles.

Suitable for: Rule-like decisions, quick baselines, and problems where nonlinear thresholds matter and a model that can be inspected is valuable.

7. Random forest Ensemble

Key idea. Train many decision trees on bootstrap samples, using random subsets of features at each split, then average regression predictions or vote across classes. Randomization makes the trees diverse; aggregation reduces variance.

Regression: f̂(x) = (1/B) Σᵦ Tᵦ(x)
Classification: majority vote of T₁(x), …, Tᴮ(x)

Pros: Strong general-purpose model for tabular data, captures nonlinear interactions, tolerates many feature types, and usually needs less tuning than boosting.

Cons: Harder to explain than one tree and can be memory-intensive. It may not extrapolate smoothly beyond the observed target range in regression; feature importance can be misleading when predictors are correlated.

Suitable for: Tabular classification or regression when you want a sturdy first high-performing model and can trade simple interpretation for accuracy.

8. Gradient boosting Ensemble

Key idea. Add small models—usually shallow trees—one after another. Each new tree is fit to reduce the current model’s loss, often by following the loss gradient. Popular implementations include XGBoost, LightGBM, CatBoost, and histogram-based gradient boosting.

Fₘ(x) = Fₘ₋₁(x) + η·hₘ(x)
hₘ is chosen to reduce the loss gradient/residuals

Pros: Often excellent predictive performance on structured/tabular data; learns nonlinearities and interactions and supports many loss functions.

Cons: Can overfit without regularization and careful validation; tuning matters. Sequential fitting is less parallel than random forests, and explanations are less direct.

Suitable for: High-accuracy tabular classification and regression, including ranking and heterogeneous business datasets. Compare against a simpler baseline and tune depth, learning rate, and number of trees.

Similarity, margins, and flexible functions

9. k-nearest neighbors (k-NN) Instance-based

Key idea. Keep the training examples. For a new point, find its k closest examples; classify by their majority label or regress by averaging their target values, optionally weighting nearer neighbors more heavily.

Classification: majority{yᵢ : i ∈ Nₖ(x)}
Regression: ŷ = (1/k) Σᵢ∈Nₖ(x) yᵢ

Pros: Simple, intuitive, makes few assumptions about the shape of the decision boundary, and training is almost immediate.

Cons: Prediction can be slow and storage-heavy. Results depend on feature scaling, distance choice, and k; irrelevant features and high-dimensional spaces make “nearest” less meaningful.

Suitable for: Smaller datasets where examples cluster by a meaningful distance, recommendation by similarity, or a transparent local baseline. Standardize numeric features and validate k.

10. Support vector machine (SVM) Classification & regression

Key idea. A linear SVM chooses a separating boundary with a wide margin between classes. A kernel lets it act as if data were mapped into a richer feature space, enabling nonlinear boundaries without explicitly constructing that space. Support vectors are the examples that constrain the boundary.

Soft-margin objective: minimize ½||w||² + CΣᵢ ξᵢ
subject to yᵢ(wᵀxᵢ+b) ≥ 1−ξᵢ, ξᵢ ≥ 0

Pros: Effective in high-dimensional spaces and can model nonlinear patterns through kernels. A useful option when the number of features is large relative to examples.

Cons: Scaling and selection of C/kernel parameters matter; kernel SVMs can be costly on large datasets. Probability estimates require additional calibration.

Suitable for: Small- or medium-sized classification problems with clear margins, text or other high-dimensional features, and nonlinear boundaries that a linear model cannot capture.

11. Neural network (multilayer perceptron / MLP) Flexible nonlinear model

Key idea. Stack layers of weighted sums and nonlinear activation functions. Training adjusts weights using backpropagation and gradient-based optimization to reduce a task-specific loss.

h⁽⁰⁾=x;   h⁽ˡ⁾=φ(W⁽ˡ⁾h⁽ˡ⁻¹⁾+b⁽ˡ⁾)
ŷ = g(W⁽ᴸ⁾h⁽ᴸ⁻¹⁾+b⁽ᴸ⁾)

Pros: Can approximate complex nonlinear mappings and supports classification and regression. Neural network architectures are the foundation of modern image, audio, and language models.

Cons: Often needs more data and tuning than simpler tabular models; training can be compute-intensive and explanations are difficult. Feature scaling and regularization are usually important.

Suitable for: Complex relationships, larger datasets, or inputs such as images, audio, and text (using architectures specialized for those data). For ordinary small tabular datasets, tree ensembles are often a strong comparison.

12. Gaussian process (GP) Probabilistic model

Key idea. Rather than selecting one function shape, define a probability distribution over possible functions. A kernel specifies how similar inputs should have correlated outputs; after observing data, the model returns a predictive mean and uncertainty.

f(x) ~ GP(m(x), k(x,x′))
For regression: y = f(x) + ε

Pros: Flexible through kernel choice and naturally provides uncertainty estimates, which help identify regions with little data.

Cons: Standard exact GP fitting scales roughly cubically with the number of training examples and can be sensitive to kernel choice; high-dimensional data are challenging.

Suitable for: Smaller datasets, smooth regression problems, scientific modeling, and active learning or optimization where uncertainty is useful.

These are starting points, not guarantees. Use a validation procedure that matches deployment, select metrics that reflect the real cost of errors, and check for leakage, imbalance, and distribution shift.
